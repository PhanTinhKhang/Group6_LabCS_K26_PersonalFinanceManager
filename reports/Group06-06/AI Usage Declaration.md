1. Scope of AI Assistance:

During this sprint, team members utilized conversational AI tools (Google Gemini) exclusively as an advisory learning aid, conceptual sounding board, and documentation assistant. AI engagement was strictly restricted to:

* Conceptual Clarification: Inquiring about low-level C++ mechanics (e.g., custom dynamic array copy constructor deep-copy semantics, stream state clearing `std::cin.clear()`, input buffer flushing, and ODR multiple-definition resolution using `inline`).
* Architectural Brainstorming: Reviewing modular separation of business logic and presentation layer, terminal formatting using `<iomanip>`, and designing clean CLI state transitions returning automatically to the Dashboard.
* Documentation & Formatting: Structuring project documentation, organizing tables, and proofreading English report text.
2. Academic Integrity & Implementation Guarantee:
* Zero AI Code Generation: No code, data structure algorithms, class definitions, were generated or copy-pasted from AI outputs into the project repository (include/, src/, test/).
* Manual Implementation: Every line of source code was manually authored, compiled, debugged, and verified by team members using local toolchains.
